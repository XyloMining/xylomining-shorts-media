One hash can vouch for thousands of transactions. The merkle root is a single hash that commits to every transaction in a block. That matters because only the 80-byte block header gets hashed for proof of work, not the full list of transactions. Change any transaction and the merkle root changes, so the header hash changes too. That is how the header protects the whole block. Did that click for you?
