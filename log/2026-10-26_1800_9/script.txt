Miners keep changing one tiny number. Here is why. Hash the same block header twice and you get the same answer, so a miner has to change something to try again. The block header has an easy-to-modify nonce field. Changing it gives a brand new hash to test. Each new hash is compared with the network target. If it does not exceed it, the block is valid proof of work. Curious how digital mining fits in? The link is in the description.
