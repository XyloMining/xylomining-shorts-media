Bitcoin changes its own difficulty. Here is how. Every 2,016 blocks, the network checks how long those blocks took, using the timestamps in each block header. The target is about two weeks. If blocks came too fast, difficulty rises, by as much as 300 percent. If blocks came too slowly, difficulty falls, by as much as 75 percent. That keeps block time near ten minutes.
