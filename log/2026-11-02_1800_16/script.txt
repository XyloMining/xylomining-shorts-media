Bitcoin mining isn't solving a puzzle. It's a lottery with a target. Miners aren't doing clever maths. They run SHA-256 hashing and look for a block header hash below the network target. If the hash is too high, the miner changes the nonce and tries again. Difficulty sets how low the hash must be, and it is recalculated every 2,016 blocks.
